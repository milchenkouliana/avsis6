# Форма обратной связи: Vercel + Telegram

Проект содержит статическую страницу и серверную Vercel Function. Форма
проверяет данные в браузере, затем функция `/api/contact` повторно проверяет их
на сервере и отправляет сообщение через Telegram Bot API.

## Структура

```text
vercel-feedback-form/
├── api/
│   └── contact.js
├── index.html
├── style.css
├── script.js
├── package.json
└── README_RU.md
```

## 1. Создание Telegram-бота

1. Откройте в Telegram официального бота `@BotFather`.
2. Выполните `/newbot`, задайте имя и username.
3. Сохраните полученный токен. Не вставляйте его в HTML или `script.js`.
4. Откройте созданного бота и нажмите **Start** или отправьте `/start`.

Чтобы получить идентификатор чата, откройте PowerShell и выполните:

```powershell
$tgToken = Read-Host "Введите токен бота"
(Invoke-RestMethod "https://api.telegram.org/bot$tgToken/getUpdates").result.message.chat.id
Remove-Variable tgToken
```

Запишите выведенное число — это `TELEGRAM_CHAT_ID`.

## 2. Загрузка проекта в GitHub через браузер

1. Создайте новый репозиторий, например `university-feedback-form`.
2. Распакуйте архив проекта.
3. На странице репозитория выберите **Add file → Upload files**.
4. Перетащите все файлы и папку `api`, затем нажмите **Commit changes**.

## 3. Публикация в Vercel

1. Войдите на `https://vercel.com` через GitHub.
2. Нажмите **New Project** и импортируйте созданный репозиторий.
3. Для **Framework Preset** оставьте `Other`.
4. До нажатия **Deploy** добавьте Environment Variables:

```text
TELEGRAM_BOT_TOKEN=токен_от_BotFather
TELEGRAM_CHAT_ID=идентификатор_чата
```

5. Для обеих переменных выберите окружение **Production**.
6. Нажмите **Deploy** и откройте выданный адрес `*.vercel.app`.

Если переменные добавлялись после первой публикации, откройте Deployments и
выполните Redeploy: старое развёртывание новые значения не получит.

## 4. Проверка

1. Попробуйте отправить пустую форму — браузер должен показать ошибки.
2. Введите некорректный email — форма не должна отправляться.
3. Заполните все поля правильно и подтвердите согласие.
4. После отправки должно появиться зелёное сообщение, а бот должен прислать
   обращение в Telegram.

## Диагностика

- `Сервис отправки пока не настроен` — не заданы переменные Vercel или не был
  выполнен Redeploy.
- `Telegram не принял сообщение` — неверен токен, chat ID или пользователь ещё
  не нажал Start у бота.
- В логах Vercel нет вызова функции — проверьте, что файл находится именно по
  пути `api/contact.js`.
- Не публикуйте токен в GitHub, HTML, JavaScript или отчёте студента.
